# План курсової роботи: «MERA»

## 1. Проблема та мета
Мета - створення вебзастосунку для демонстрації авторського одягу (футболок, худі), контролю залишків та оформлення замовлень. Застосунок усуває проблему неструктурованої інформації про лімітовані релізи та ручної обробки запитів у приватних повідомленнях соцмереж.

## 2. Цільова аудиторія
- Покупці (перегляд доступних товарів, статусів наявності, деталей колекцій).
- Менеджер бренду (актуалізація каталогу, зміна статусів наявності дропів).

## 3. Сценарії використання
- **Поточний етап (Л 1.1)**: Перегляд каталогу актуальних дропів зі статусами доступності, короткою інформацією та ціною.
- **Заплановані етапи (наступні лабораторні роботи)**:
  - Детальні картки товарів із вибором розмірів (Л 1.2 / Л 2.2).
  - Стан кошика та інтерактивний вибір моделей через React Hooks (Л 2.1).
  - Форма подання заявки / оформлення замовлення з валідацією (Л 3.1).
  - Підключення асинхронного джерела даних / API (Л 3.2).
